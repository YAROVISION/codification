# Skill: Міграція оглядів судової практики

Застосовується для перенесення нормалізованого огляду з єдиного markdown-файлу в окремі файли сегментів і встановлення точних зв'язків із класифікацією законодавства.

## Коли застосовувати
- Користувач каже «міграція», «запусти міграцію», «розділи на сегменти та встанови зв'язки».
- Завершено нормалізацію markdown-файлу огляду і потрібно оновити папку `documents/segments/<doc_name>/` та записи в базі `data/classifier.sqlite`.
- Застосовується **тільки до вказаного користувачем файлу** (або активного опрацьованого файлу).

## Що робить пайплайн міграції
1. **Очищення старих сегментів**: повністю видаляє папку `documents/segments/<doc_name>/` з усіма застарілими файлами.
2. **Очищення старих зв'язків у БД**: видаляє з таблиці `mapped_segments` у `data/classifier.sqlite` всі попередні записи з `file_path LIKE '%<doc_name>%'`.
3. **Розбиття на окремі файли**:
   - Парсить файл `documents/markdown/<doc_name>/<doc_name>.md` за мітками `<!-- === SEGMENT: ... === -->`.
   - **Технічні сегменти**: (`PREAMBLE`, `APPENDIX`, `РОЗДІЛ I..IV`, `II. ДОСУДОВЕ РОЗСЛІДУВАННЯ`, `II. ЗАСТОСУВАННЯ НОРМ ОСОБЛИВОЇ ЧАСТИНИ...`, тощо) зберігаються в службові файли (`00_Preamble.md`, `01_Rozdil_I.md`, `03_Osoblyva_chastyna.md`, `04_Dosudove.md`, `99_Appendix.md`).
   - **Змістовні (юридичні) сегменти**: зберігаються у файли з чіткою префіксацією (`OP_01.1_segment.md`, `KK_01.1_segment.md`, `KPK_01.1_segment.md` тощо).
4. **Мапінг до класифікатора (`smart_mapper.py`)**:
   - **Аналіз початкових речень сегмента**: спочатку визначається стаття і кодекс (наприклад, ст. 49 КК, ст. 245 КПК, ст. 459 КПК, ст. 130 КУпАП, ст. 268 КАСУ), про які йдеться у назві/префіксі та перших реченнях сегмента (тезі).
   - **Пріоритет за умовчанням**: спочатку за умовчанням перевіряється відповідність нормам:
     - **Кримінального кодексу України** (рубрика `250 10 ...`) або **Кримінального процесуального кодексу України** (рубрика `250 20 ...`) у головній категорії **«Кримінальне законодавство» (`250`)**;
     - **Кодексу адміністративного судочинства України** (рубрика `240 20 ...`) або **Кодексу України про адміністративні правопорушення** (рубрика `240 10 ...`) у головній категорії **«Адміністративне законодавство» (`240`)**.
   - **Інші розділи класифікації**: інші розділи класифікатора (наприклад, цивільне, господарське законодавство, військова служба тощо) перевіряються лише тоді, коли норма або спірне правовідношення явно стосується іншої галузі права або не врегульоване відповідними профільними кодексами (КК/КПК, КАСУ/КУпАП).
   - **Технічні сегменти ігноруються** та не додаються до таблиці `mapped_segments`.
   - Для кожного юридичного сегмента підбирається найкраща рубрика класифікатора, оцінка впевненості (confidence) та обґрунтування (LLM reasoning).
5. **Генерація сторінки взаємозв'язку (`correlation/<doc_name>.html`)**:
   - Створює окрему інтерактивну HTML-сторінку у папці `correlation/` (та `public/correlation/`), яка містить повний звіт мапінгу сегментів до класифікації з пошуком та фільтрами.
   - Сторінка відкривається через активну кнопку у колонці «Сегменти» на веб-сторінці `http://127.0.0.1:8080/digest.html`.
6. **Валідація**: перевіряє кількість створених файлів і кількість записів у базі даних.

## Як виконати міграцію
Запустити команду:
```bash
python3 migrate_document.py documents/markdown/<doc_name>/<doc_name>.md
```

## Перевірка результату
```python
import sqlite3
conn = sqlite3.connect('data/classifier.sqlite')
cur = conn.cursor()
cur.execute("SELECT count(*) FROM mapped_segments WHERE file_path LIKE '%<doc_name>%'")
print('Замаплено сегментів:', cur.fetchone()[0])
```
