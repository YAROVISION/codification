# Skill: Міграція оглядів судової практики

Застосовується для перенесення нормалізованого огляду з єдиного markdown-файлу в окремі файли сегментів у папці `documents/segments/<doc_name>/`.

## Коли застосовувати
- Користувач каже **«міграція»**, **«запусти міграцію»**, **«розділи на сегменти»**.
- Завершено нормалізацію markdown-файлу огляду і потрібно наповнити папку `documents/segments/<doc_name>/` готовими сегментами.
- Застосовується **тільки до вказаного користувачем файлу** (або активного опрацьованого файлу).

## Що робить пайплайн міграції
1. **Очищення старих сегментів**:
   - Повністю видаляє або очищає папку `documents/segments/<doc_name>/` з усіма застарілими файлами перед створенням нових.
2. **Розбиття на окремі файли**:
   - Парсить файл `documents/markdown/<doc_name>/<doc_name>.md` за мітками `<!-- === SEGMENT: ... === -->`.
   - **Технічні сегменти**: (`PREAMBLE`, `APPENDIX`, `РОЗДІЛ I..IV`, `II. ДОСУДОВЕ РОЗСЛІДУВАННЯ`, `II. ЗАСТОСУВАННЯ НОРМ ОСОБЛИВОЇ ЧАСТИНИ...` тощо) зберігаються в окремі службові файли (`00_Preamble.md`, `01_Rozdil_I.md`, `03_Osoblyva_chastyna.md`, `04_Dosudove.md`, `99_Appendix.md`).
   - **Змістовні (юридичні) сегменти**: зберігаються у файли з чіткою префіксацією (`OP_01.1_segment.md`, `KK_01.1_segment.md`, `KPK_01.1_segment.md` тощо). Кожен такий файл містить одну сформульовану судову позицію/тезу з реквізитами справи.
3. **Валідація**:
   - Перевіряє кількість створених файлів сегментів на диску, співвідношення змістовних та технічних сегментів.

> [!NOTE]
> Встановлення взаємозв'язків між створеними сегментами та класифікатором законодавства здійснюється окремим скілом **`classification`** (викликається за словом «класифікація»).

## Як виконати міграцію
Запустити команду:
```bash
python3 migrate_document.py documents/markdown/<doc_name>/<doc_name>.md
```

## Перевірка результату
```bash
ls -la documents/segments/<doc_name>/
```
Або через Python:
```python
from pathlib import Path
seg_dir = Path("documents/segments/<doc_name>")
files = list(seg_dir.glob("*.md"))
print(f"Створено файлів сегментів: {len(files)}")
```
