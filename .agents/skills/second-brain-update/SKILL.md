# Skill: оновлення другого мозку

Мозок проєкту лежить у `brain/` (карта: `brain/INDEX.md`).

## Процедура
1. Прочитай `brain/INDEX.md` і `brain/progress.md`.
2. Додай запис у **початок** `brain/progress.md` за шаблоном:
   ```
   ## ДД.ММ.РРРР
   - Зроблено: ...
   - Стан: документ, розділ, рядок/сегмент, де зупинились
   - Далі: ...
   ```
3. Нове рішення про формат/процес → `brain/decisions.md` (рішення + причина + дата).
4. Нова проблема/особливість даних → `brain/issues.md`.
5. Нові терміни → `brain/glossary.md`.
6. **Формування скілів.** Якщо за день було повторюване завдання (≥2 рази виконана однакова послідовність дій), а скіла для нього ще немає:
   - створи `.agents/skills/<назва>/SKILL.md` (frontmatter `name`, `description` з тригерами «використовуй, коли...»);
   - винеси повторюваний код у `scripts/`;
   - додай рядок у таблицю скілів у `brain/INDEX.md`.
   Якщо скіл уже є, але ти знайшов уточнення чи підводний камінь, онови його.
7. Скажи користувачеві, що саме оновлено (список файлів, 3–5 пунктів).

## Правила
- Пиши стисло, українською, без води.
- Не видаляй старі записи в `progress.md`, лише додавай нові.
- Не дублюй те, що вже є в `README.md`, `design.md`, `MAPPING_PLAN.md`, посилайся на них.
