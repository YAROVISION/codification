# Єдиний класифікатор правових актів України (Юридична класифікація ВРУ)

Проєкт для збору, структурування, аналізу та перетворення офіційного юридичного класифікатора порталу «Законодавство України» ([zakon.rada.gov.ua/laws/main/klas](https://zakon.rada.gov.ua/laws/main/klas)) на повноцінну **семантичну базу даних**.

---

## 📊 Загальні характеристики зібраного датасету

- **Всього вузлів класифікатора:** `1,043`
- **Рівень 1 (Головні галузі права):** `28` розділів
- **Рівень 2 (Підгалузі):** `372` підрозділи
- **Рівень 3 (Предметні рубрики):** `543` рубрики
- **Рівень 4 (Спеціалізовані підтеми):** `100` рубрик
- **Сумарний обсяг облікованих актів у системі:** понад `500,000` документів

## 📦 Опис збережених форматів

### 1. `data/classifier.json` (Ієрархічне дерево)
Містить масив із 28 кореневих галузей права, кожна з яких рекурсивно містить список `children`:
```json
{
  "code": "10",
  "name": "Основи суспільного ладу",
  "level": 1,
  "total_docs_count": 172714,
  "direct_docs_count": 693,
  "branch_url": "https://zakon.rada.gov.ua/laws/main/j1",
  "direct_url": "https://zakon.rada.gov.ua/laws/main/jj1",
  "children": [
    {
      "code": "10 10",
      "name": "Конституція",
      "level": 2,
      "parent_code": "10",
      "children": [...]
    }
  ]
}
```

### 2. `data/classifier.csv` (Таблиця)
Колонки:
- `code` — унікальний код (наприклад, `10`, `10 10`, `10 10 10`)
- `level` — рівень вкладеності (1..4)
- `parent_code` — код безпосереднього батьківського вузла
- `name` — оригінальна назва
- `clean_name` — назва, очищена від перехресних посилань
- `has_children` / `children_count` — наявність і кількість підкатегорій
- `total_docs_count` — сумарна кількість актів у цій гілці
- `direct_docs_count` — кількість актів, класифікованих безпосередньо у цей вузол
- `branch_url` — посилання на вибірку всіх актів гілки (`/j...`)
- `direct_url` — посилання на акти, прив'язані безпосередньо (`/jj...`)
- `path_codes` — повний ланцюжок кодів (хлібні крихти)
- `path_names` — повний текстовий шлях (наприклад, `Основи суспільного ладу / Конституція / Прийняття`)
- `cross_references` — перехресні посилання (наприклад, `20 20`)
- `semantic_text` — готовий текстовий блок для формування векторних ембеддінгів

### 3. `data/classifier.md` (Markdown)
- Зведена аналітична таблиця з усіма 28 основними галузями права, лічильниками актів та прямими посиланнями на ВРУ.
- Повне інтерактивне дерево з 1043 категорій з відступами, бейджами кількості документів та перехресними посиланнями.

### 4. `data/classifier.sqlite` (Семантична база даних)
Схема оптимізована для побудови семантичної пошукової системи, графа знань та RAG:
- `categories`: основна таблиця з індексами за `code`, `parent_code`, `level`, `clean_name`.
- `categories_fts`: віртуальна таблиця **FTS5** (повнотекстовий пошук за назвами, шляхами та контекстом з морфологією).
- `semantic_relations`: таблиця семантичних ребер (перехресні зв'язки, відсилки `see_also`).
- `documents`: таблиця під майбутній викачаний корпус законів та нормативних актів.
- Поля `embedding` (`BLOB`) та `semantic_text` готові для збереження векторів моделей (SentenceTransformers, OpenAI, Gemini).

## 🖥️ Візуальний веб-інтерфейс (Web UI)

Для комфортної роботи із класифікатором створено сучасний інтерактивний веб-інтерфейс (Single Page Application) із темною темою, скляним неоморфізмом та швидким FTS5-пошуком.

### Можливості інтерфейсу:
1. **Інтерактивне дерево рубрик:** Згортання/розгортання гілок, підсвічування рівнів, миттєва фільтрація назв у сайдбарі.
2. **Картка розділу:** Детальна інформація про категорію, код, рівень, лічильники актів та хлібні крихти для повернення до предків.
3. **Прямі посилання на ВРУ:** Кнопки переходу до повної гілки або прямих документів на порталі `zakon.rada.gov.ua`.
4. **Сітка підкатегорій:** Клікабельні картки дочірніх рубрик для швидкого заглиблення в структуру.
5. **Семантичний блок:** Перехресні зв'язки (наприклад, `див. 20 20`), кнопки копіювання JSON вузла та тексту для ембеддінгів.
6. **Глобальний повнотекстовий пошук (Ctrl+K):** Миттєвий пошук по 1,043 вузлах через SQLite FTS5.

### Запуск веб-інтерфейсу:
```bash
python server.py
```
Після запуску відкрийте браузер за адресою: **[http://127.0.0.1:8080](http://127.0.0.1:8080)**

## 🚀 Як використовувати Python API (`semantic_db.py`)

```python
from semantic_db import SemanticClassifierDB

db = SemanticClassifierDB()

# 1. Отримати 28 головних галузей права
roots = db.get_roots()
for r in roots[:5]:
    print(r['code'], r['clean_name'], r['total_docs_count'])

# 2. Отримати прямих нащадків
children = db.get_children("10")
for c in children:
    print(c['code'], c['clean_name'])

# 3. Знайти ланцюжок предків (хлібні крихти)
ancestors = db.get_ancestors("10 10 10")
# [10] Основи суспільного ладу -> [10 10] Конституція -> [10 10 10] Прийняття

# 4. Швидкий повнотекстовий пошук через FTS5
results = db.search_fts("подат*")
for res in results:
    print(f"[{res['code']}] {res['clean_name']} (Шлях: {res['path_names']})")

# 5. Отримати текстовий корпус для генерації ембеддінгів
corpus = db.get_corpus_for_embedding()
# Кожен запис містить id, code, clean_name, path_names, semantic_text
```

## 🧠 Дорожня карта перетворення на повноцінну семантичну БД

1. **Генерація векторних ембеддінгів (Vector Search):**
   - Прогнати поле `semantic_text` через україномовну модель ембеддінгів (наприклад, `intfloat/multilingual-e5-base`, `sentence-transformers/paraphrase-multilingual-mpnet-base-v2` або `text-embedding-3`).
   - Зберегти отримані вектори у стовпець `embedding` або підключити розширення `sqlite-vec` / ChromaDB.
2. **Семантичний граф зв'язків:**
   - Автоматично виявити споріднені теми між різними галузями права (наприклад, `Військова служба` в Обороні $\leftrightarrow$ `Військові пенсії` в Соцзахисті).
3. **Парсинг та прив'язка нормативних актів:**
   - Викачати переліки законів через наявні у базі посилання `direct_url` (`/jj...`) та `branch_url` (`/j...`).
   - Зберегти акти в таблицю `documents` з прив'язкою до рубрик кодифікатора.
