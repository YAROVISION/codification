# Інструкції для агента (проєкт codification)

Проєкт: класифікатор правових актів України + обробка оглядів судової практики
(PDF → markdown → сегменти → мапінг до рубрик класифікатора).

## Другий мозок: обов'язково на початку кожної розмови
1. Прочитай `brain/INDEX.md` та `brain/progress.md` (останні записи), щоб знати контекст попередніх днів.
2. Дивись `brain/conventions.md` перед будь-якою правкою оглядів.
3. Для повторюваних завдань перевір таблицю скілів у `brain/INDEX.md` і використовуй відповідний скіл.

## Наприкінці роботи
- Коли користувач каже «підсумуй день», «онови пам'ять», «зафіксуй» або виконано велику порцію роботи, застосуй скіл `second-brain-update`.
- Якщо повторюєш однакову послідовність дій удруге, створи для неї скіл (див. `second-brain-update`, крок 6).

## Критичні правила роботи з файлами
- Файли в `documents/markdown/` можуть містити некоректні UTF-8 байти. Не використовуй для них інструменти редагування, які падають на кодуванні. Правь Python-скриптом з `errors='surrogateescape'`, `newline=''`.
- Шукай блоки за текстом, а не за номерами рядків: редактор користувача має власний буфер, файл на диску може відставати.
- Після правки перевіряй результат на диску (`grep`/`sed`) і нагадуй перезавантажити файл у редакторі.
- Відповідай користувачеві українською, стисло.
