1.7. Про порушення процедури визначення викупної ціни як перешкоду для
примусового відчуження земельної ділянки для суспільних потреб

Чернівецька міськрада звернулася до апеляційного адміністративного суду, як суду
першої інстанції, з позовом до фізичної особи, про примусове відчуження у комунальну
власність, з мотивів суспільної необхідності чотирьох земельних ділянок
сільськогосподарського призначення. В обґрунтування позовних вимог міськрадою
вказано те, що нею прийнято рішення, у зв’язку із відсутністю можливості розширення
кладовища для організації місць поховань за рахунок земель запасу міста, викупити для
суспільних потреб земельні ділянки, які розташовані на території міської територіальної
громади і належать на праві приватної власності відповідачці. Проте, останньою не
надано згоди на викуп цих земельних ділянок, що стало підставою для звернення
до суду з цим позовом. Суд першої інстанції відмовив у задоволенні позову. Апеляційну

скаргу позивач мотивував тим, що відповідачка фактично не погоджується із викупною
ціною земельної ділянки. При цьому апелянт вказував на те, що оскільки судом першої
інстанції поставлено під сумнів надану позивачем експертну грошову оцінку, суд мав всі
правові підстави для призначення повторної експертизи. Верховний Суд залишив
апеляційну скаргу без задоволення, а рішення суду першої інстанції без змін.

Верховний Суд звернув увагу, що визначальною підставою для примусового
відчуження земельної ділянки, що знаходиться в приватній власності
з мотивів суспільної необхідності є неотримання згоди власника земельної
ділянки з її викупом для суспільних потреб, а також обов’язкове дотримання
процедури щодо прийняття рішення, повідомлення власника про викуп
земельної ділянки для суспільних потреб, забезпечення права на участь
у переговорах щодо умов викупу, узгодження умов договору купівлі-продажу,
істотною умовою якого є викупна ціна, яка передує виникненню підстав для
примусового відчуження земельних ділянок, інших об’єктів нерухомого
майна, що на них розміщені, з мотивів суспільної необхідності.
Суд зазначив, що визначена позивачем викупна ціна не може бути
використана для прийняття рішення про викуп земельної ділянки для
суспільних потреб, оскільки звіт про експертну грошову оцінку земельної
ділянки щодо примусового викупу якої виник спір, складений без ретельного
аналізу даних про об’єкт оцінки, фізичних характеристик, правового стану,
